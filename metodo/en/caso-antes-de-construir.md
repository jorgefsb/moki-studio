# Case before building

Before touching code, the studio writes the case: what the problem is, which number measures it today and which number we expect afterwards.

Examples:

- Repetitive music: today it repeats at 80 s; the goal is 5 minutes without repeating. Result: 1,000 s without repeating across 200 seeds.
- First 10 seconds: a first-time bot died 0 out of 24 times before 10 s. We did not change the start because the number said there was no problem there.

No number, no piece. If the number does not improve, the piece does not go in.
