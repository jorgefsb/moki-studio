# Studio priorities

Jorge's rule from Nov 7, 2026.

1. **Gameplay and game design**, including game feel and micro-interactions: how it feels to jump, crash and win.
2. **How it looks.**
3. **Technology and optimization**, except when it touches how the game feels. A frame hitch, a delayed jump or a slow load count as gameplay.

"More fun weighs more than prettier."

Fun is measured with play numbers: bots, a simulated player and the play thermometer. Not with art critics. See [[medir-diversion]].
